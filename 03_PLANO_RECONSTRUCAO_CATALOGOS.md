# 03 - Plano de reconstrução dos catálogos

## Objetivo

Reconstruir os catálogos da EveFit a partir de conceitos treináveis, e não a partir de listas soltas de exercícios.

## Princípio

```text
Primeiro conceitos.
Depois exercícios.
Depois filtros.
Depois textos.
Depois testes.
```

## Fase 1 - Fundação conceptual

Criar e validar:

```text
domínios
capacidades
conceitos
exercícios
variações
modificadores
filtros
contextos de uso
```

Critério de sucesso:

```text
conseguimos explicar qualquer exercício como derivado de um conceito
conseguimos decidir se algo é variação ou modificador
conseguimos evitar duplicados por categoria
```

## Fase 2 - Musculação por músculos e funções

Ordem obrigatória:

```text
1. Listar músculos e estruturas treináveis.
2. Para cada músculo, listar funções anatómicas.
3. Para cada função, listar capacidades treináveis.
4. Para cada capacidade, listar padrões.
5. Para cada padrão, criar conceitos.
6. Para cada conceito, derivar famílias de exercícios.
7. Para cada família, listar exercícios concretos.
8. Só depois mapear equipamento, local e filtros.
```

## Fase 10 - Testes

Criar testes para:

```text
nenhum conceito sem domínio
nenhum exercício sem concept_id
nenhum exercício sem primary_type
nenhum exercício invisível
nenhum exercício duplicado por filtro
nenhum cardio sem intensidade
nenhuma arte marcial sem arte ou habilidade
nenhuma mobilidade sem articulação
nenhum alongamento sem zona ou método
nenhuma recuperação sem objetivo
nenhum texto genérico
nenhum equipamento incoerente
nenhum filtro errado
```

## Critério final de pronto

```text
cada exercício responde a que conceito treina
cada conceito tem exercícios derivados
cada exercício tem categoria primária
cada exercício tem contextos de uso
cada exercício aparece nos filtros certos
cada exercício não aparece em filtros errados
cada descrição ensina um iniciante
os testes impedem regressões
```
