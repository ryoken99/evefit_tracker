# 17 - Mobilidade: exercícios derivados

## Objetivo

Este ficheiro transforma os conceitos do ficheiro `16_MOBILIDADE_CONCEITOS_POR_ARTICULACAO.md` em exercícios derivados.

A regra principal é:

```text
Mobilidade é controlo ativo de amplitude articular.
O exercício pode cruzar aquecimento, recuperação, musculação ou artes marciais, mas mantém identidade canónica única.
```

```text

equipamento

```

# Regras de duplicação

## Mobilidade versus elasticidade

```text
Se o foco é controlar ativamente a amplitude, fica em mobilidade.
Se o foco é manter uma posição passiva para ganhar comprimento ou tolerância, fica em elasticidade.
O mesmo nome pode aparecer nos dois domínios apenas se a execução e o objetivo forem diferentes.
```

## Mobilidade versus recuperação

```text
Mobilidade leve pós-treino pode aparecer em recuperação.
Mas o exercício não deve ser duplicado.
A diferença está em use_contexts e objetivo da sessão.
```

## Mobilidade versus artes marciais

```text
Technical stand-up lento, sprawl lento, pivots e câmaras de pontapé podem ser mobilidade quando treinam controlo.
Quando o foco é técnica marcial ou aplicação, aparecem como artes marciais.
```
