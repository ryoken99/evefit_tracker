# 16 - Mobilidade: conceitos por articulação

## Objetivo

Este ficheiro reconstrói o domínio de mobilidade da EveFit a partir de articulações, funções e conceitos treináveis.

A regra base é:

```text
Mobilidade não é alongamento passivo.
Mobilidade é controlo ativo de amplitude articular.
```

Um exercício de mobilidade deve responder a:

```text
Que articulação está a mover?
Que grau de liberdade está a ser treinado?
A amplitude é ativa ou passiva?
Que controlo está a ser desenvolvido?
Para que tarefa isto serve?
```

## Diferença entre mobilidade, elasticidade e recuperação

```text
Mobilidade = amplitude ativa com controlo.
Elasticidade = tolerância e ganho de comprimento dos tecidos.
Recuperação = reduzir fadiga, tensão, rigidez ou ativação.
```

Exemplo:

```text
90/90 ativo = mobilidade de anca.
Alongamento passivo dos adutores = elasticidade.
Mobilidade leve de anca pós-treino = recuperação, se o objetivo for baixar rigidez.
```

## Modelo conceptual da mobilidade

```text
Articulação
  > Grau de liberdade
    > Amplitude ativa
      > Controlo
        > Posição
          > Tarefa específica
            > Exercícios derivados
```

## Capacidades treináveis em mobilidade

# Regras de descrição

Cada exercício de mobilidade deve explicar:

```text

ritmo

```

## Descrição errada

```text
Faz este movimento para melhorar mobilidade.
```

## Descrição correta

```text
Objetivo:
Melhorar controlo ativo da rotação externa da anca.

Como fazer:
1. Senta-te em posição 90/90.
2. Mantém tronco alto e respiração controlada.
3. Tenta levantar ligeiramente o tornozelo ou joelho sem perder a posição.
4. Move devagar e sem compensar com a lombar.
5. Volta à posição inicial com controlo.

Erros comuns:
- Rodar a lombar para roubar amplitude.
- Ir depressa demais.
- Forçar dor na anca ou joelho.
```
