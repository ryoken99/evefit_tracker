# 19 - Elasticidade: exercícios derivados

## Objetivo

Este ficheiro transforma os conceitos do ficheiro `18_ELASTICIDADE_CONCEITOS_POR_ZONA.md` em exercícios derivados e canónicos.

A regra principal é:

```text
Elasticidade é tolerância progressiva a posições alongadas.
O mesmo exercício pode aparecer em recuperação, mobilidade ou artes marciais, mas só deve existir uma vez como entidade canónica.
```

## Campos usados

```text
concept_id
exercício
zona
método
intensidade
nível
equipamento
locais
contextos
filtros prováveis
cuidados
```

## Regra de segurança

Alongamento deve criar sensação controlada, não dor agressiva. Para pescoço, ombro, joelho, lombar e tendão de Aquiles, a progressão deve ser conservadora.

# Regras de duplicação

## Elasticidade versus mobilidade

```text
Se o foco é manter uma posição alongada e respirar, fica em elasticidade.
Se o foco é mover ativamente a articulação com controlo, fica em mobilidade.
```

## Elasticidade versus recuperação

```text
Se a sessão usa alongamentos leves para baixar tensão, o exercício aparece em recuperação como contexto.
A entidade principal continua a ser o exercício canónico, com secondary_type recuperação.
```

## Elasticidade versus artes marciais

```text
Alongamentos para pontapés, guarda, BJJ e aberturas podem aparecer em artes marciais.
Mas só são técnica marcial quando há execução técnica, não apenas posição alongada.
```
