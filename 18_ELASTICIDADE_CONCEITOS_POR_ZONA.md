# 18 - Elasticidade: conceitos por zona

## Objetivo

Este ficheiro reconstrói o domínio de elasticidade e alongamentos da EveFit a partir de zonas, tecidos, métodos e objetivos.

A regra base é:

```text
Elasticidade não é mobilidade.
Elasticidade é tolerância e ganho progressivo de amplitude em tecidos e posições alongadas.
```

## Diferença entre elasticidade, mobilidade e recuperação

```text
Elasticidade = manter ou explorar uma posição alongada para ganhar tolerância, relaxamento ou comprimento funcional.
Mobilidade = controlar ativamente uma amplitude articular.
Recuperação = baixar fadiga, rigidez, dor ligeira ou ativação.
```

Exemplo:

```text
90/90 lift-off = mobilidade.
90/90 passivo para glúteo = elasticidade.
90/90 leve pós-treino para relaxar = recuperação, com secondary_type elasticidade ou mobilidade conforme execução.
```

## Modelo conceptual da elasticidade

```text
Zona ou músculo
  > Tecido ou cadeia
    > Direção de alongamento
      > Método
        > Intensidade
          > Contexto
            > Exercícios derivados
```

## Métodos principais

```text
alongamento estático
alongamento dinâmico
alongamento ativo assistido
PNF
relaxamento em posição alongada
alongamento específico para tarefa
progressão para abertura
```

## Intensidades

```text
muito leve
leve
moderada
intensa controlada
avançada
```

## Contextos de uso

```text
pós-treino
cooldown
recuperação leve
sessão própria de flexibilidade
preparação para pontapés
preparação para guarda
prevenção
relaxamento
```

# Métodos e quando usar

| Método | Uso principal | Cuidados |
|---|---|---|
| Alongamento estático | Pós-treino, sessão de flexibilidade, relaxamento | Não forçar dor. Manter respiração. |
| Alongamento dinâmico | Aquecimento e preparação técnica | Não usar amplitude máxima fria. |
| Ativo assistido | Ganhar amplitude mantendo algum controlo | Apoio deve ajudar, não forçar. |
| PNF | Progressão de flexibilidade em pessoas com bom controlo | Usar contrações leves e não máximas. |
| Relaxamento em posição alongada | Baixar tensão e rigidez | Intensidade baixa. |
| Progressão para abertura | Objetivos como front split e side split | Longo prazo, com progressões e sem pressa. |

# Mapa de cruzamentos

| Conceito | Domínio principal | Também pode aparecer em | Motivo |
|---|---|---|---|
| 90/90 passivo | Elasticidade | Mobilidade, Jiu-Jitsu / BJJ | É elasticidade quando o foco é relaxar e manter posição, mobilidade quando há lift-off ou controlo ativo. |
| Rock back de adutores | Mobilidade | Elasticidade | Dinâmico e ativo é mobilidade, manutenção passiva é elasticidade. |
| Couch stretch | Elasticidade | Mobilidade, Recuperação | Pode ser alongamento principal ou cooldown leve, conforme intensidade. |
| Pigeon passivo | Elasticidade | Mobilidade, Recuperação | Passivo é elasticidade, ativo é mobilidade. |

# Regras de descrição

Cada exercício de elasticidade deve explicar:

```text
objetivo
zona alvo
posição inicial
como entrar na posição
como manter
respiração
intensidade esperada
tempo típico
erros comuns
versão mais fácil
versão mais difícil
cuidados
quando usar
```

## Descrição errada

```text
Alongar a perna durante algum tempo.
```

## Descrição correta

```text
Objetivo:
Alongar o posterior de coxa sem forçar a lombar.

Como fazer:
1. Deita-te de barriga para cima.
2. Passa uma toalha atrás da coxa ou do pé.
3. Eleva a perna até sentires alongamento confortável atrás da coxa.
4. Mantém a lombar apoiada no chão.
5. Respira devagar e mantém a posição pelo tempo definido.

Erros comuns:
- Puxar com força até doer.
- Levantar a anca do chão.
- Dobrar a lombar para ganhar falsa amplitude.
```
